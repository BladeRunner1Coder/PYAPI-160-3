### Приложение определяет ваш IP адрес через запрос на сайт <https://api.ipify.org/>, затем определяет ваше местоположение (город), посылая запрос с вашим IP адресом на сайт <https://ipinfo.io/>, а также создаёт на вашем Яндекс Диске (<https://360.yandex.ru/disk/>) папку, в которую помещает JSON файл с вашим IP адресом и местоположением.

#### Приложению необходим OAuth token из <https://yandex.ru/dev/disk/poligon/>

#### Этот токен должен быть помещён в переменную "TOKEN" в модуле ".env" (как показано в модуле "example.env").

#### Команда "getip = GetIP()" создаёт объект "getip" класса "GetIP", который позволяет вам использовать его методы, чтобы определить и использовать ваш IP адрес.

#### Команда "address = GetAddress(getip.get_ip())" создаёт объект "address" класса "GetAddress", который принимает в качестве параметра IP адрес, хранящийся в объекте предыдущего класса, и позволяет вам использовать его методы, чтобы определить и использовать ваше местоположение.

#### Команда "YD = YandexDisk(token)" создаёт объект "YD" класса "YandexDisk", который принимает в качестве параметра ваш TOKEN для Яндекс Диска и позволяет вам использовать его методы для создания папки "Your IP city" (если её ещё нет) на вашем Яндекс диске и для создания в этой папке JSON файла с вашим IP адресом и местоположением.

#### Приложение информирует вас об успешном (или нет) выполнении всех важных этапов, а также иллюстрирует продвижение выполнения приложения посредством численно-графической шкалы от 0 до 100%.
